# bank-callback

Weiterleitungsseite für die Bankanbindung von LifeOS.

Enable Banking leitet nach dem Bank-Login hierher zurück. Die Seite springt sofort nach `lifeos://bank-callback` weiter, wo die App den Code auffängt. Sie lädt nichts von außen, speichert nichts und enthält keinen App-Code.

Adresse für Enable Banking und für LifeOS (mit `/` am Ende):

    https://dev-kuro1.github.io/bank-callback/
